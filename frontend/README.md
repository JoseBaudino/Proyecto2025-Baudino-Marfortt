# AgroGestión 360 - Frontend

Aplicación React + Vite del proyecto **AgroGestión 360**. La documentación completa está en el [README principal](../README.md).

## Scripts

| Comando           | Descripción                                          |
|-------------------|------------------------------------------------------|
| `npm install`     | Instala las dependencias                             |
| `npm run dev`     | Levanta el servidor de desarrollo (http://localhost:5173) |
| `npm test`        | Ejecuta los tests con Jest + React Testing Library   |
| `npm run lint`    | Revisa el código con ESLint                          |
| `npm run build`   | Genera el build de producción en `../docs` (GitHub Pages) |
| `npm run preview` | Sirve el build de producción localmente              |
